# مدير كلمات المرور الآمن — Secure Password Manager

مشروع تخرج — تخصص الأمن السيبراني — المؤسسة العامة للتدريب التقني والمهني (TVTC) وأكاديمية نمو — 2026

تطبيق مكتبي بواجهة عربية كاملة (RTL) لإدارة كلمات المرور، يخزّن البيانات محليًا على الجهاز
بتشفير **AES-256-GCM** مع اشتقاق المفاتيح عبر **Argon2id**، دون أي اتصال بالشبكة أو خدمات سحابية.

---

## الميزات الأساسية

- خزنة محلية مشفّرة تُنشأ بكلمة مرور رئيسية ولا تُفتح إلا بها.
- إدارة كاملة للحسابات: إضافة، تعديل، حذف بتأكيد، بحث فوري (عربي/إنجليزي).
- حفظ اسم الموقع، اسم المستخدم، الرابط، والملاحظات الاختيارية لكل حساب.
- إخفاء كلمات المرور افتراضيًا (نقاط تغطية) مع إظهار انتقائي بطلب المستخدم.
- نسخ آمن إلى الحافظة مع مسح تلقائي بعد المدة المضبوطة (افتراضيًا 30 ثانية).
- مولّد كلمات مرور عشوائية (مصدر عشوائية مشفّري `secrets`) بخيارات طول وفئات وحروف ملتبسة.
- محلل قوة كلمة المرور: طول، فئات، كلمات شائعة مسرّبة، تكرار وتسلسلات، إنتروبيا، وزمن تخمين تقديري.
- كشف الحسابات ذات كلمات المرور الضعيفة والمكررة ولوحة تحكم بمستوى أمان الخزنة.
- قفل تلقائي عند الخمول (افتراضيًا 5 دقائق) مع مسح مفتاح التشفير من الذاكرة.
- خروج آمن يمسح المفتاح والحافظة، وتجميد الشاشة 30 ثانية بعد 5 محاولات فتح خاطئة.
- تغيير كلمة المرور الرئيسية بملح جديد فريد وإعادة تشفير كامل للخزنة.
- صفحة تعليمية تشرح الفرق بين التجزئة والتشفير وآليات حماية التطبيق وحدودها.

## البنية الأمنية

| الطبقة | التفاصيل |
|---|---|
| اشتقاق المفاتيح | Argon2id — 3 مرورات، ذاكرة 64 MiB، 4 خيوط، مخرج 256 بت، ملح 128 بت فريد لكل خزنة |
| التشفير | AES-256-GCM مع nonce عشوائي 96 بت فريد لكل عملية حفظ ووسم سلامة 128 بت |
| مكافحة العبث | ربط رأس الملف (الملح + المعاملات + nonce) كبيانات مُوثَّقة (AAD) بوسم السلامة |
| الكتابة | كتابة ذرّية (ملف مؤقت ثم استبدال) لمنع تلف الملف |
| الذاكرة | المفتاح يعيش في الذاكرة فقط ويُمسح بالتصفير عند القفل أو الخروج |
| التخزين | ملف واحد `vault.spm` في `%APPDATA%\SecurePasswordManager` على Windows — ولا يُحذف عند إزالة البرنامج إلا بطلب صريح |

ملاحظة أمنية مهمة: لا يوجد نظام آمن بنسبة 100%، وأقوى نقطة في هذا التطبيق هي كلمة المرور
الرئيسية؛ اخترها طويلة وعشوائية (16 حرفًا أو أكثر) واحفظها في مكان آمن. لا توجد آلية
استرجاع عند نسيانها، وهذا مقصود في التصميم.

## التشغيل على Windows

1. ثبّت بايثون 3.10 أو أحدث من [python.org](https://www.python.org/downloads/) مع تفعيل خيار **Add to PATH**.
2. انسخ مجلد `Application` إلى أي مكان على الجهاز.
3. شغّل الملف **run.bat** بالنقر المزدوج (يثبّت المكتبات ويشغّل التطبيق)،
   أو يدويًا من نافذة الأوامر داخل المجلد:

```bat
python -m pip install -r requirements.txt
python main.py
```

## التشغيل على Linux / macOS (للتطوير)

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

> ملاحظة: تم تطوير التطبيق واختباره على بيئة Linux وتصميمه للعمل على Windows بنفس
> الملفات؛ جميع المكتبات المستخدمة متعددة المنصات.

## بناء حزمة التثبيت (ملف تنفيذي + Setup.exe)

يسلّم المشروع **مجموعة بناء كاملة** تُنتج على Windows الملفين التاليين:

1. **`SecurePasswordManager.exe`** — ملف تنفيذي واحد يحوي كل المكتبات والخطوط والأصول،
   يعمل على أي جهاز Windows **دون تثبيت Python** (PyInstaller + ملف `SecurePasswordManager.spec`).
2. **`SecurePasswordManager_Setup.exe`** — مثبّت كامل (Inno Setup 6 + سكربت
   `installer/SecurePasswordManager.iss`) يقوم بـ:
   - التثبيت في `C:\Program Files\SecurePasswordManager`.
   - إنشاء **اختصار على سطح المكتب** و**عنصر في قائمة ابدأ**.
   - الإزالة القياسية (Uninstall) مع **الاحتفاظ ببيانات المستخدم**
     في `%APPDATA%\SecurePasswordManager`، ولا تُحذف إلا بطلب صريح يظهر في رسالة عند الإزالة.

### متطلبات البناء (مرة واحدة)

| الأداة | الرابط |
|---|---|
| Python 3.10+ (مع تفعيل Add to PATH) | https://www.python.org/downloads/ |
| Inno Setup 6 (مجاني) | https://jrsoftware.org/isdl.php |
| اتصال إنترنت أول مرة فقط | لتحميل المكتبات عبر pip |

### خطوات البناء

1. انسخ مجلد `Application` كاملًا إلى جهاز Windows.
2. شغّل **`build_all.bat`** بالنقر المزدوج — أمر واحد يبني الملفين بالترتيب.
3. المخرجات:
   - `dist\SecurePasswordManager.exe`
   - `installer\Output\SecurePasswordManager_Setup.exe`

> ملاحظة صريحة: بيئة تجهيز المشروع كانت Linux، و PyInstaller لا ينتج ملفات Windows
> إلا من داخل Windows؛ لذلك سُلّمت ملفات البناء الجاهزة بدل ادعاء بناء غير منفَّذ،
> والتفاصيل الكاملة في ملف `Application/BUILD_NOTE.md`.

## بنية المجلد

```
Application/
├── main.py                        نقطة التشغيل
├── run.bat                        تشغيل سريع أثناء التطوير (تثبيت + تشغيل)
├── requirements.txt               المكتبات المطلوبة
├── build_exe.bat                  بناء SecurePasswordManager.exe (PyInstaller)
├── build_installer.bat            بناء Setup.exe (Inno Setup)
├── build_all.bat                  بناء الاثنين بأمر واحد
├── SecurePasswordManager.spec     ملف بناء PyInstaller
├── installer/
│   └── SecurePasswordManager.iss  سكربت المثبّت (اختصارات + إزالة + حماية البيانات)
├── BUILD_NOTE.md                  شرح بناء الحزمة والملاحظات الصريحة
├── fonts/                         خط Noto Sans Arabic المرفق (Regular/Bold)
├── assets/                        شعار التطبيق وأيقونة EXE (app_logo.png / app_icon.ico)
└── spm/
    ├── crypto.py                  وحدة التشفير (Argon2id + AES-256-GCM)
    ├── vault.py                   إدارة الخزنة والتخزين المشفّر
    ├── passwords.py               المولّد والمحلل والكلمات الشائعة والكشف عن التكرار
    └── ui/                        الواجهات (11 شاشة + النافذة الرئيسية)
```
